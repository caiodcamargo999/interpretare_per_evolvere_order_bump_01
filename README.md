# Area Riservata & Download — Kit Calligrafia Perfetta (Order Bump)

Progetto indipendente per la pagina di download dell'Order Bump **Kit Calligrafia Perfetta - Scrittura Chiara e Sicura**.

## Deliverable
- File PDF incluso in `public/Kit_Calligrafia_Perfetta-orderbump.pdf` (e alias `public/Kit_Calligrafia_Perfetta.pdf`).
- 40 Pagine didattiche in formato A4 pronte da stampare.

## Esecuzione in Locale
```bash
npm run dev
```
La pagina si avvia su `http://localhost:3006`.

## Deploy su Vercel
1. Connetti questa cartella o il relativo repository GitHub su Vercel.
2. Vercel rileverà automaticamente il build Vite (`npm run build`).
3. Imposta il dominio o sottodominio desiderato (es. `calligrafia.tuodominio.com` o `orderbump.tuodominio.com`).
